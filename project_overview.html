Research Requirements

  • RQ1: accuracy, precision, recall, F1, FAR, FRR + 95% CI
  • RQ2: lighting, distance, angle robustness (3 conditions each)
  • RQ3: per-stage latency — mean, P50, P95
  • RQ4: baseline comparison vs manual vs fingerprint
  • RQ5: ablation — recognition / +quality / +zone / +liveness
  • Wilson 95% CI on every proportion
  • Sample size n on every metric row
  • Anti-fabrication: no placeholder numbers anywhere
  • Threshold evidence-selected (POST /experiments/threshold-sweep)
  • Train / val / test sets kept separate
  • Liveness — EXPERIMENTAL; clearly labelled in UI and docs
🔐

Security

  • bcrypt password hashing — no plaintext ever
  • HS256 JWT tokens — 8h expiry
  • Role-based access: super_admin / hod / coordinator / faculty
  • WebSocket JWT auth — 5s timeout to authenticate
  • Auth rate limiting — configurable via .env
  • Face embeddings: binary only, never exposed via API
  • Audit log: every state change logged with IP
  • Input validation via Pydantic on all endpoints
  • No secrets committed — .env.example only
  • DB constraints enforce no-duplicate attendance
  • In-process rate limiter (note: resets on restart)
